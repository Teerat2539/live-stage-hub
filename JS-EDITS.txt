update-K-auto — รายการแก้ JS/ข้อมูล (ไม่เปลี่ยนชื่อฟังก์ชัน/ID เดิม)

Firebase ใหม่ (อนุมัติแล้ว): rooms/{ห้อง}/autoAdvance {enabled, paused, songId, endsAt}
Firebase ฟิลด์ใหม่: songs/{id}/duration (วินาที) — ไม่กรอก = ไม่เก็บ

index.html
 + window.lshAutoAdv (ใหม่ ทั้งก้อน): ตัวเลื่อนอัตโนมัติส่วนกลาง ทำงานทุกหน้า
     ฟัง rooms/{ห้อง}/autoAdvance และ rooms/{ห้อง}/queue, tick ทุก 1 วินาที
     ครบเวลา -> transaction ที่ rooms/{ห้อง}/queue เลื่อน playing->played, ถัดไป->playing + จัดสถานะ next/standby
     (เลื่อนเฉพาะถ้าเพลงที่เล่นอยู่ยังเป็นเพลงที่นับเวลา = กันเลื่อนซ้ำ)
     ไม่ทำงานกับ guest/admin
 ~ lshShowTimer.bind(): เพิ่ม 1 บรรทัด เรียก lshAutoAdv.bind(r)
 ~ lshShowTimer.unbind(): เพิ่ม 1 บรรทัด เรียก lshAutoAdv.unbind()
 ~ lshSongKit.saveSongData(): payload เพิ่ม duration (ถ้ากรอก) + refreshDurations()
 ~ lshSongKit.openForm()/openDrawer(): แสดง/กรอกความยาว mm:ss
 + MARKUP ป๊อปอัพเพลง: ช่อง #formDurMin #formDurSec และ #detailDuration
 + sprite: ไอคอน i-pause

queue.html
 + markup ใน #queueShowBar: .qsb-auto (#qaPause, #qaSwitch)
 + updateAutoUi(), lshAutoToggle(), lshAutoPauseToggle(); updateShowBar() เรียก updateAutoUi
 ~ การ์ด "กำลังเล่น": ข้อความหุ้มด้วย span.q-play-lbl (แสดง "· เหลือ m:ss" / "· พัก")

monitor.html
 ~ processQueueData(): เพิ่มเช็ค ถ้าไม่มี #mPlayingTitle (ออกจากหน้าแล้ว) ให้ return — กัน error จากตัวฟังที่ค้างเมื่อคิวถูกเลื่อนอัตโนมัติขณะอยู่หน้าอื่น

style.css: ท้ายไฟล์ เพิ่มบล็อก "เลื่อนเพลงอัตโนมัติ" (.qsb-auto, .qsb-pp, .dur-wrap)
